# THAIME Dictionary & N-gram Data

This directory contains compiled data files used by the engine at runtime.

## Contents

- `dict/` - Compiled trie dictionary files (`.bin`). Binary artifacts generated by
  the [`thaime-nlp`](https://github.com/mimocha/thaime-nlp) pipeline.
- `input/` - N-gram binary files (`.bin`). Pre-scored language model data generated
  by the [`thaime-nlp`](https://github.com/mimocha/thaime-nlp) pipeline.

## Generation

Data is generated from within the [thaime-nlp](https://github.com/mimocha/thaime-nlp)
repository. Run the following commands **in that repo**:

```bash
# Full trie pipeline
python -m pipelines trie run

# Full n-gram pipeline
python -m pipelines ngram run
```

Output binaries can be found under: `pipelines/outputs/ngram/thaime_ngram_*.bin`

Copy the desired files into the appropriate subdirectory here (`dict/` or `input/`).

## Formats

### Trie Dictionary

Binary serialized trie containing romanized keys mapped to Thai word entries with
frequency weights. See `crates/thaime_engine/src/trie.rs` for the loader.

### N-gram Binary

Pre-scored log₁₀-probability language model (unigrams, bigrams, trigrams).
See `.docs/ngram-handover-v1.md` for the full binary format specification.

File naming convention: `thaime_ngram_v{format_version}_mc{min_count}.bin`
