# THAIME Dictionary Data

This directory contains compiled dictionary files used by the engine at runtime.

## Contents

- `dict/` - Compiled trie dictionary files (`.bin`). These are binary artifacts
  generated by the [`thaime-candidate`](https://github.com/mimocha/thaime-candidate)
  pipeline and are not hand-edited.

## Generation

To regenerate the dictionary from the NLP pipeline:

```bash
./scripts/generate-dict.sh
```

See the `thaime-candidate` repository for details on the data processing pipeline.

## Format

The dictionary uses a binary serialization format (initially bincode) containing:
- Romanized keys → Thai word entries
- Frequency weights for candidate ranking
- Metadata (version, generation timestamp)

The exact format may evolve as the engine matures.
